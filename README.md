# Minefetch
A Minecraft plugin like FastFetch/NeoFetch that shows information about the server.
![preview](demo_in_game.png)
![preview](demo_in_console.png)
Paper 1.21+

You can customize the default ASCII art in ascii.yml file.
You can also edit the displayed messages in the config.yml file.
You can turn off modules or change their order.

# Build from source
*Requires Java 21*
1. Clone repo
2. $ `mvn package`
3. Enjoy!
